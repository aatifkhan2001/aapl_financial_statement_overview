## 📌 Project Overview

This project analyzes Apple's financial performance using publicly available financial data retrieved through an API.

A Python script was used to fetch financial statement data through an API connection, load the retrieved information into a Pandas DataFrame, and prepare the dataset for further analysis and visualization. The processed data was then modeled and transformed into an interactive Power BI dashboard.

The objective of this project was to analyze Apple's profitability, financial position, and performance trends from 2020 to 2024 using publicly available financial information.

---

## 📂 Data Source & Acquisition

The financial data used in this project was obtained from a publicly available financial data API.

The data extraction process included:

- Connecting to the financial data API using Python
- Fetching Apple's financial statement information
- Loading API responses into a Pandas DataFrame
- Structuring the retrieved data for analysis
- Preparing the dataset for Power BI reporting

The dataset contains summarized financial information covering Apple's performance from **2020 to 2024**.

---

## 📊 Dataset

The extracted dataset includes financial statement metrics such as:

- Revenue
- Cost of Revenue
- Operating Expenses
- Net Income
- Assets
- Liabilities
- Equity
- Other income statement and balance sheet metrics

The data was transformed from its original API format into a structured analytical dataset suitable for financial reporting.

---

## 🛠️ Data Preparation & Transformation

The extracted data was cleaned, transformed, and modeled to support financial analysis.

Key preparation steps included:

- Cleaning and restructuring API-generated data
- Organizing financial statement categories
- Preparing income statement and balance sheet structures
- Creating calculated financial metrics and ratios
- Building a Power BI data model for interactive reporting

---

## 📊 Dashboard Features

The dashboard provides an interactive overview of Apple's financial performance.

Users can analyze:

- Revenue and profitability trends
- Income statement performance
- Balance sheet composition
- Asset, liability, and equity movements
- Financial KPI trends
- Year-over-year performance changes

Interactive filters allow users to explore financial performance across different years and reporting periods.
